# Hamoor data

Public stock data feeding the Hamoor iOS app
(<https://github.com/alialm98/hamoor> — coming soon).

Live URLs (served by Firebase Hosting):
- <https://hamoor-1ee70.web.app/stocks.json> — what the iOS app polls every 15 min
- `https://hamoor-1ee70.web.app/prices/<TICKER>.json` — full per-stock history

## What's here

- `boursa-kuwait-stocks.json` — master list of Boursa Kuwait tickers with
  sector / market metadata.
- `fy2025-dividends.json` — curated dividend amounts and dates for the
  past few fiscal years (until we can extract them from the official PDFs
  programmatically).
- `output/` — generated data, regenerated by the GitHub Actions cron:
  - `output/stocks.json` — single-file blob with every stock's metadata
    plus the last 90 days of price history.
  - `output/prices/<TICKER>.json` — full daily price history per stock
    (5+ years).
  - `output/manifest.json` — index of available per-stock price files.
  - `output/diagnostic.json` — tiny OTA-test affordance read by the
    Settings → OTA Diagnostic row in the iOS app.
- `fetch_boursa_history.py` — one-shot historical backfill for every
  stock. Pulls 5 years of daily closes from Yahoo Finance.
- `update_prices.py` — incremental updater. Merges the last few days
  into `output/prices/` and writes the bundled slim copy at
  `../Hamoor/Resources/prices/` when running locally (skipped on the
  GitHub Actions runner — the iOS repo isn't checked out there).
- `firebase.json`, `.firebaserc`, `firestore.rules` — Firebase config
  for the Hosting + Firestore deploy.
- `.github/workflows/update-prices.yml` — the cron that runs every 15
  min Sun–Thu 09:30-13:00 Kuwait time, fetches prices, commits + pushes
  the data, and deploys to Firebase Hosting.

## How prices flow in production

```
yfinance (Yahoo) ──▶ GitHub Actions ──▶ this repo ──▶ Firebase Hosting ──▶ iOS app
                     (cron, every 15m)                (CDN, 60s cache)     (15m poll + foreground refresh)
```

No Mac dependency. Workflow runs on GitHub's infrastructure even when
every developer machine is off.

## Source

Closing prices come from Yahoo Finance via the `yfinance` Python package.
Boursa Kuwait disclosures, board members, and dividend event dates are
fetched live in-app from the public `boursakuwait.com.kw/data-api`
endpoints — no caching in this repo.

## Manual / one-off updates

If you ever need to run the updater locally (e.g. to test a script
change before pushing it):

```bash
cd data
python3 update_prices.py                                   # rolling 10-day window
python3 update_prices.py --from 2026-05-13 --to 2026-05-14 # explicit range
```

To deploy a local one-off without waiting for the cron:

```bash
cd data
firebase deploy --only hosting
```

To update the Firestore security rules:

```bash
cd data
firebase deploy --only firestore:rules
```

## Watching the cron

The workflow runs at <https://github.com/alialm98/hamoor-data/actions>.
Each run takes ~2-3 min. Failed runs send GitHub email notifications.
